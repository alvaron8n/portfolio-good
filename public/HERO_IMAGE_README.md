# Hero Phone Image

**IMPORTANTE**: Copia tu imagen del móvil 3D a esta ubicación:

```
public/hero-phone.png
```

La imagen debe ser la que subiste (fff.png) con el dashboard de IA y los elementos flotantes.

## Alternativa temporal

Si no puedes copiar la imagen inmediatamente, puedes usar un placeholder:

```bash
# En la raíz del proyecto
curl -o public/hero-phone.png "https://placehold.co/400x700/1a1a2e/8b5cf6?text=Phone+3D"
```

O simplemente copia manualmente el archivo `fff.png` a `public/hero-phone.png`.
